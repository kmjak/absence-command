公欠申請を半自動で行うSkillです。以下の手順に従って処理を進めてください。

---

## Step 0: サブコマンドの振り分け

`$ARGUMENTS` の先頭がサブコマンド名の場合は、対応する手順ファイルを読み込んでそちらに処理を委ねてください。
サブコマンド名を除いた残りの引数（`--check` や日付など）は、そのまま委譲先の `$ARGUMENTS` として扱います。
委譲先の処理が終わったらこのコマンドは終了し、Step 1 以降には進まないでください。

| 先頭の引数 | 委譲先 | 内容 |
|-----------|--------|------|
| `setup` | `.claude/commands/absence-setup.md` | 初期セットアップ |

```
/absence setup           # セットアップを対話で実行
/absence setup --check   # 現状の診断だけ（設定は変更しない）
```

どのサブコマンドにも当てはまらない場合（引数なし、または日付が渡された場合）は、
そのまま Step 1 へ進んで通常の手動申請を行ってください。

---

## Step 1: 日付入力

`$ARGUMENTS` に日付（`YYYY-MM-DD` または `YYYYMMDD`）が渡されている場合は、
**それを申請日として扱い、この Step での質問はスキップ**してください
（`/absence-list` から日付を選んで呼ばれた場合がこれに当たります）。

**この手順（Step 1〜Step 7）が扱う日付は常に1日だけです。**
複数の日付が渡された場合は、**1日目について Step 7 まで完了させてから**、
2日目を新しい申請として Step 1 からやり直してください。
複数の日付を1回の申請にまとめてはいけません（詳細は Step 6 を参照）。

渡されていない場合のみ、以下を聞いてください:

```
公欠を申請する日付を入力してください（例: 2026-07-03）:
```

入力された日付の曜日を算出し、`data/weekdays.md` に記載されている曜日に含まれるか確認してください。

**含まれない場合**は「その日は授業がないため申請できません」と伝えて処理を終了してください。

**含まれる場合**は `YYYY-MM-DD (曜日)` の形式で確認を表示してから次のステップへ。

例: `2026-07-04 (土曜日)`

---

## Step 2: 授業選択

`data/timetable.md` を読み込み、入力された日付の曜日に対応する授業を全て取得してください。

**授業が存在しない曜日の場合**は「その曜日には授業がありません」と伝えて処理を終了してください。

授業が存在する場合は番号選択形式で提示し、公欠を申請する授業を複数選択させてください。

その際、**実際にどのコマが欠席になっているか**を以下で取得し、該当するコマに `←欠席` を付けて
既定の選択候補として提示してください（ポータル側のデータなので、出席済みのコマを誤って申請するのを防げます）。

```bash
./scripts/absence_list.sh --detail <YYYY-MM-DD>
```

取得に失敗した場合（セッション切れ等）は印を付けずにそのまま提示して構いません。

```
公欠を申請する授業を選んでください（複数選択可）:

  1) 1限/ネットワーク演習Ⅱ/山本先生  ←欠席
  2) 2限/ネットワーク演習Ⅱ/山本先生  ←欠席

番号をカンマ区切りで入力してください（Enterで「←欠席」の全てを選択）:
```

ユーザーが入力したら次のステップへ。Enter のみの場合は `←欠席` が付いたコマを全て選択したものとして扱ってください。

---

## Step 3: 公欠日付の特定

Step 1 で入力された日付をYYYYMMDD形式に変換して使用してください。

---

## Step 4: 写真の確認

以下を聞いてください:

```
公欠理由の証明写真はありますか？
写真がある場合はファイルパスを入力してください（なければEnterを押してください）:
```

---

## Step 5-A: 写真がない場合

公欠の理由をテキストで入力させてください:

```
公欠の理由を入力してください:
```

入力されたら **Step 6** へ進んでください。画像名と画像BASE64は空文字で渡してください。

---

## Step 5-B: 写真がある場合

以下を聞いてください:

```
公欠理由を…
  (1) 自分で入力する
  (2) Claudeに写真をもとに考えてもらう
```

### (1) 自分で入力する場合

公欠の理由をテキストで入力させてください。その後 **Step 6** へ。

### (2) Claudeに考えさせる場合

写真を読み込み、イベント・行事の内容を把握したうえで、以下のフォーマットで簡潔な公欠理由を生成してください:

```
「イベント名」に参加するためです。
（参加理由を1〜2文で。自分が何を知りたかった・解決したかった・学びたかったかを学生らしい口調で）
```

例:
```
「DBデザイン勉強会」に参加するためです。
DBのid管理方法をUUIDにするかintのauto incrementを使うかで悩んでいたので参加します。
```

生成した理由をユーザーに提示し、確認を取ってから **Step 6** へ。

---

## Step 6: run.sh の実行

`./scripts/submit.sh` と `./scripts/run.sh` の内容を確認したうえで、以下の形式で `./scripts/run.sh` を実行してください。

写真がある場合は事前に以下のコマンドでBASE64に変換してください（データURIプレフィックスつき・改行なし）:
```bash
IMAGE_BASE64="data:image/png;base64,$(base64 -i <写真のパス> | tr -d '\n')"
```

**1回の `run.sh` 実行＝1日分の申請です。DATE1〜DATE5 には必ず「同じ1つの日付」だけを入れてください。**
DATE/PERIODS の5つの枠は、**その日の中で選択された複数のコマ**を並べるためのものであり、
別々の日をまとめて送るための枠ではありません。
異なる日付を DATE1 と DATE2 に入れて1回で送ると、複数日が1つの申請フォームに入ってしまい不正な申請になります。

- 申請したい日が複数ある場合は、**日付ごとに `run.sh` を別々に実行**してください
  （3日分なら `run.sh` を3回実行する）。
- 1回目の `run.sh` の結果を確認し、Step 7 のログ保存まで終えてから次の日付に進んでください。

Step 2 で選択された授業（同一日のコマ）を DATE/PERIODS のペアとして順番に渡してください（最大5件）。
DATE1〜DATE5 のうち使用する枠には、すべて **Step 3 で求めた同じ YYYYMMDD** を入れます。
授業が5件未満の場合、残りのDATE・PERIODSは空文字を渡してください。

PERIODSのフォーマット: `x限目/授業名/講師名先生`（data/timetable.mdの形式から生成）

```bash
./scripts/run.sh \
  "<理由>" \
  "<DATE1>" "<PERIODS1>" \
  "<DATE2>" "<PERIODS2>" \
  "<DATE3>" "<PERIODS3>" \
  "<DATE4>" "<PERIODS4>" \
  "<DATE5>" "<PERIODS5>" \
  "<IMAGE_NAME>" "<IMAGE_BASE64>"
```

授業が足りない枠は空文字 `""` で埋めてください。

1日分（例: 2026-07-02 の1限・2限）を送る場合の例:

```bash
./scripts/run.sh \
  "<理由>" \
  "20260702" "1限目/ネットワーク演習Ⅱ/山本先生" \
  "20260702" "2限目/ネットワーク演習Ⅱ/山本先生" \
  "" "" \
  "" "" \
  "" "" \
  "" ""
```

同じ理由で 2026-07-18 も申請したい場合は、上の実行が終わってから
**別の `run.sh` 実行**として `20260718` の分を送ってください（1回にまとめない）。

---

## Step 7: ログの保存

ログも**申請1件（＝1日）につき1ファイル**を作成してください。
複数日をまとめて1ファイルにしないこと。

`logs/log/` ディレクトリに以下の形式でログファイルを保存してください。

ファイル名: `YYYY-MM-DD-<title>.md`
- `YYYY-MM-DD` は公欠で休む日付
- `<title>` は公欠内容から適切に考えてください（例: `network-exercise`, `business-training`）

内容:

```markdown
# 公欠申請ログ

## 申請日時
<実行した日時>

## 公欠日
<YYYY-MM-DD>

## 対象授業
<選択した授業一覧>

## 公欠理由
<使用した理由>

## 証明写真
<写真ファイル名 or なし>

## 申請結果
<scripts/run.shの実行結果>
```

`logs/log/` ディレクトリが存在しない場合は作成してください。
