欠席になっている日付を一覧で出力するコマンドです。

学生ポータルの「出欠確認」ページが内部で使っている API エンドポイント
（`/PortalManagementWeb/public/attendancedetail/search`）を `scripts/attendance.sh` 経由で直接叩き、
欠席（出欠区分=2）のデータを構造化 JSON で取得します。HTMLのスクレイピングは行いません。

---

## 実行

`$ARGUMENTS` を範囲指定として `scripts/absence_list.sh` に渡して実行してください。
**引数が無い場合は既定（`fy` = 今年度・4/1以降）** で実行します。

```bash
./scripts/absence_list.sh <RANGE>
```

`absence_list.sh` が内部で `attendance.sh` を呼び（自動ログイン＋全ページ取得）、
指定範囲で絞り込み、日付ごとに集約して整形表示します。出力をそのままユーザーに提示してください。

### 指定できる範囲（RANGE）

| 指定 | 意味 |
|------|------|
| （なし） / `fy` | 今年度（4/1以降）※デフォルト |
| `1y` | 直近1年 |
| `6m` | 直近6ヶ月 |
| `3m` | 直近3ヶ月 |
| `1m` | 直近1ヶ月 |
| `all` | 全期間 |
| `YYYYMMDD` | 指定日以降 |

出力例:

```
欠席一覧（今年度（2026/04以降） / 全 37 コマ・17 日分）

   1) 2026-07-22 (水) … ネットワーク演習Ⅱ（2コマ）
   2) 2026-07-18 (土) … 設計・開発（2コマ）
  ...
```

エラー（セッション切れ等）で有効な JSON が返らない場合は、`.env` の `STUDENT_PORTAL_PHPSESSID` を
最新のものに更新するよう案内して終了してください。

---

## 日付を選んで公欠申請へ

一覧を提示したあと、続けて以下を聞いてください:

```
公欠を申請する日付を選んでください（番号 or YYYY-MM-DD / 不要なら Enter）:
```

- **Enter（空入力）** … 一覧の表示だけで終了してください。
- **番号 / 日付が入力された場合** … その日付を確定し、`.claude/commands/absence.md`（`/absence`）の
  手順を **Step 1 の日付として確定済みの状態から** 実行してください。
  日付を聞き直す必要はありません（Step 1 の質問はスキップ）。

該当する番号が一覧に無い場合は、その旨を伝えてもう一度選ばせてください。

## 補足

- 出欠区分そのものを変えて確認したい場合は `scripts/attendance.sh` を直接使えます
  （第1引数: `1:出席 2:欠席 3:遅刻 4:早退 5:公欠 6:理欠`、第2引数: 年度）。
  例: 公欠済みを確認 → `./scripts/attendance.sh 5`
- 同じ欠席データで範囲だけ変えて何度も見たいときは、一度取得した JSON を使い回せます。
  例: `./scripts/attendance.sh > /tmp/absence.json` 後に
  `ABSENCE_JSON=/tmp/absence.json ./scripts/absence_list.sh 1m`
